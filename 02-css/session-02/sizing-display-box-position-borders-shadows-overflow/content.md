# Session 2B — Sizing, Display, Box Model, Position, Borders, Shadows, Overflow

**Duration:** 2.5 hours — **Goal:** Control size and placement precisely.

## 1. Sizing
### Slides
- width/height, min/max, fit-content/min-content/max-content, aspect-ratio
### Code
`css.box{width:10rem; aspect-ratio:16/9}
` 
### Talk track
> Avoid fixed height unless necessary.

## 2. Display
### Slides
- block/inline/inline-block/flex/grid, none vs visibility:hidden vs opacity:0
### Code
`css.flex{display:flex}
` 
### Talk track
> display:none removes from layout.

## 3. The Box Model
### Slides
- content/padding/border/margin, box-sizing:border-box, margin collapsing
### Code
`css*{box-sizing:border-box}
` 
### Talk track
> Use border-box globally.

## 4. Position
### Slides
- static/relative/absolute/fixed/sticky, z-index, stacking context
### Code
`css.abs{position:absolute;top:0;left:0}
` 
### Talk track
> Position relative to containing block.

## 5. Border, Shadows & Overflow
### Slides
- border-radius, outline vs border, box-shadow, drop-shadow, overflow, clip-path
### Code
`css.card{border-radius:.5rem;box-shadow:0 4px 12px rgba(0,0,0,.1);overflow:hidden}
` 
### Talk track
> Use shadows to convey elevation.

## Recap
- Layout + visual chrome mastered.
