## Suggested preparation order

1. Read **Web fonts**, then write the system stack from memory.
2. Read **Styling text** and **text overflow**, then build a type scale.
3. Read **box model**, then reproduce the global `border-box` reset.
4. Read **`position`** and **stacking context**, then predict a badge's containing block.
5. Skim the reference pages for any property you need details on.
