# Session 2 — Live Demo

A **profile card** walkthrough covering: system fonts + type scale, text truncation, `rgba` vs `opacity`, grayscale hover, sizing with `aspect-ratio`, the box model, sticky header, absolute badge, and hover elevation.

**How to run it**

1. Open `starter/index.html` in the browser — bare structure, no styles.
2. Build `finished/styles.css` step by step with the students, typing from memory.
3. Each step maps to a topic in `content.md` (fonts → text → box model → position → effects).
4. `index-combined.html` in each folder is the same page with the CSS inlined in a `<style>` tag for quick review.
