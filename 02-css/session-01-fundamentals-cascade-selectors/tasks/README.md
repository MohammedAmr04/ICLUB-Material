# Session 1 — Tasks

Practice the fundamentals without touching layout yet.

## Task 1 — Basic Selectors
Create an HTML page with one <h1>, two <p>, one <div>, and one <button>. Use CSS to:

- Change the heading colour
- Change paragraph colour
- Give the <div> a background colour
- Change the button text colour

## Task 2 — Classes and IDs
Use:
`html
<h1 id='main-title'>My Website</h1>
<p class='description'>First paragraph</p>
<p class='description'>Second paragraph</p>
`
Style the ID and both paragraphs using the class.

## Task 3 — Colours & Backgrounds
Create elements demonstrating named, HEX, RGB, RGBA, HSL, and OKLCH colours. Also demonstrate:
- `background-color`, `background-image`, `background-size`, `background-position`, `background-repeat`, `background-attachment`
- `linear-gradient()`, `radial-gradient()`, `conic-gradient()`, `repeating-linear-gradient()`
- multiple backgrounds (comma-separated) and `background-clip: text` (with `color: transparent`)

Compare the outputs.

## Task 4 — Cascade & Specificity
Recreate the example from content.md (Section 4) and predict who wins before applying styles.

## Task 5 — Units & Tokens
Rebuild a small card using :root tokens and em units. Add :hover with a derived hsl() shade.

## Mini Project (from content.md)
Build a simple personal profile page with at least three selector types, tokens, and an external stylesheet.
