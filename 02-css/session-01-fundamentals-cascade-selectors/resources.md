## Suggested preparation order

1. Read [CSS basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics) and build a minimal external stylesheet.
2. Practice selectors on [CSS Diner](https://flukeout.github.io/).
3. Read cascade, specificity, and inheritance, then predict winners before checking DevTools.
4. Read values and units, then rewrite `px` values as `rem` in a small example.
5. Read color basics and tokens, then add `:root` variables to an existing page.
