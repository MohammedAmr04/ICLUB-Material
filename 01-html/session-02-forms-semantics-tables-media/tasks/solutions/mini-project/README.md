# Task 09 — Mini-project solution

`index.html` is the complete capstone page: semantic landmarks, a labelled
registration form, a data table, and audio + video with captions.

## Media

The `media/` folder contains runnable placeholders:

- `intro.mp3` (MDN CC0 sample) and `intro.wav` (generated tone)
- `lesson.mp4` / `lesson.webm` (MDN CC0 sample)
- `lesson-poster.jpg` (placeholder image)
- `lesson-en.vtt` — a **valid** WebVTT file that already loads

Swap in your own files any time; the paths are what matter.
