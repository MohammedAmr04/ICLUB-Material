# Session 2 — Resources

Organized by topic. Review and practice each before presenting.

## Forms & Inputs

**MDN — HTML Forms**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_forms

- Type: official tutorial with examples.
- Use it to explain: form structure, input controls, labels, buttons, validation.
- Practice: build a registration form with name, email, and a course-track select.

**MDN — How to Structure a Web Form**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/How_to_structure_a_web_form

**MDN — HTML Input Element Reference**
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input

## Form Controls

## Tables

## General HTML review

**freeCodeCamp — Learn HTML: Beginner's Course**
https://www.freecodecamp.org/news/learn-html-beginners-course/

- Type: beginner course with video instruction.
- Use it for: reviewing fundamentals and seeing extra examples of semantic elements, tables, and forms.
- Note: broad review, not a replacement for focused prep of this session's five topics.

## Suggested preparation order

1. Read **HTML Forms**, then practice the form examples in `content.md` sections 1 and 2.
2. Read **HTML Table Basics** and build a small table yourself.
3. Read **HTML Video and Audio** and test local media files.
4. Watch the relevant parts of the **freeCodeCamp** course to review concepts.
5. Consult the additional references for details on a specific element.
