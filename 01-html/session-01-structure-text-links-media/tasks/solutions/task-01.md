# Task 01 — Solutions

1. **Site name at the top** → `<header>` (with the site name inside, often in an `h1` on the homepage). It is the banner landmark.
2. **A customer quote** → `<blockquote>` with `<cite>` for the source. It is a quotation, not a paragraph.
3. **Main navigation** → `<nav>`. It is the navigation landmark screen readers can jump to.
4. **Related but not essential aside** → `<aside>`. It is a complementary landmark.
5. **Paragraph of body copy** → `<p>`. The default block of running text.
6. **An important word inside a sentence** → `<strong>`. Conveys importance, unlike `<b>` which only looks bold.
7. **A clickable phone number** → `<a href="tel:+201234567890">`. The `tel:` scheme triggers the dialler on mobile.
