# Session 1 — Resources

Organized by topic. Review and practice each before presenting.

## How HTML Works

**MDN — Basic HTML syntax**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Basic_HTML_syntax

- Type: official tutorial with examples.
- Use it to explain: what HTML is, elements, and how the browser reads markup.

**MDN — Structuring content with HTML**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content

## Document Structure

**MDN — What's in the head? Metadata in HTML**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Webpage_metadata

- Use it for: the `charset`, viewport, `<title>`, description, and Open Graph tags.
- Practice: write the mandatory head from memory (charset, viewport, title, `lang`).

## Tags, Elements & Attributes

**MDN — HTML elements reference**
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements

**MDN — HTML attribute reference**
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes

- Use it for: looking up void elements, boolean attributes, and per-element attributes.

## Text Content

**MDN — Headings and paragraphs**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Headings_and_paragraphs

**MDN — Inline text semantics**
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements

- Use it for: heading outline, `<p>`, `<strong>`, `<em>`, `<small>`, `<mark>`, `<del>`, `<code>`.

## Links

**MDN — Creating hyperlinks**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Creating_hyperlinks

- Use it for: `href`, fragment links, `target`/`rel`, `mailto:`, `tel:`, and the `download` attribute.

## Paths & File Structure

**MDN — Dealing with files**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Getting_started/Environment_setup/Dealing_with_files

- Use it for: relative vs absolute paths, `../`, and a sensible folder layout.

## Images

**MDN — Images in HTML**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_images

**MDN — Responsive images**
https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Responsive_images

https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img

- Use it for: `alt`, `width`/`height`, `loading`, `decoding`, `srcset`/`sizes`, and `<picture>`.

## Lists

**MDN — HTML lists**
https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/HTML_lists

**MDN — The ul element**
https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ul

- Use it for: `<ul>`, `<ol>` attributes (`start`, `reversed`), nested lists, and `<dl>`.

## Entities

**MDN — Character reference**
https://developer.mozilla.org/en-US/docs/Glossary/Character_reference

- Use it for: named and numeric entities, `&nbsp;`, and the bidi controls (`&lrm;`, `&rlm;`).

## General HTML review

**freeCodeCamp — Learn HTML: Beginner's Course**
https://www.freecodecamp.org/news/learn-html-beginners-course/

- Type: beginner course with video instruction.
- Use it for: reviewing fundamentals and seeing extra examples of semantic elements and structure.

## Suggested preparation order

1. Read **Basic HTML syntax**, then build the minimum document from memory.
2. Read **What's in the head?**, then write the mandatory head without looking.
3. Read **Creating hyperlinks** and practice relative paths end to end.
4. Read **Images in HTML** and **HTML lists**, then build the profile-page demo.
5. Skim the reference pages for any element you need details on.
