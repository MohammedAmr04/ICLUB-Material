# Session 1 — Live Demo

Three live-coding exercises from the session plan. Do them in order.

## Exercise 1 — Skeleton from memory (10 min)

Blank file. Type a complete valid document from memory: doctype, `html lang`,
`head` with charset + viewport + title, `body` with one `h1` and one paragraph.
Narrate each line as you type. No copy-paste.

## Exercise 2 — Plain text to semantic HTML (30 min)

Open [`starter/index.html`](./starter/index.html). It is raw text with no
markup. Convert it into a real page using headings, paragraphs, inline
formatting, links, an image, and lists.

Compare against [`finished/index.html`](./finished/index.html) at the end.

## Exercise 3 — Refactor the div soup (20 min)

Covered as a task: see `../tasks/README.md`, Task 09.

## Teaching notes

- Build Exercise 1 wrong on purpose first (forget the doctype), then show the
  browser landing in quirks mode. The mistake teaches better than the fix.
- In Exercise 2, pause on **alt text** and on the **heading order** — those are
  the two things the assessment checks hardest.
- Keep the finished file open in a second tab and run it through the W3C
  validator live.
